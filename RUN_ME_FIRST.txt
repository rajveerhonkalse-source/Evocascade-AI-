EVOCASCADE AI — RUN THIS ON THE NEW LAPTOP
===========================================

1. Extract the ZIP completely.
2. Install Python 3.10+ (recommended 3.11/3.12), Node.js 20+, and Git.
3. Double-click SETUP_WINDOWS.bat once. Internet is needed for the first package install.
4. After setup finishes, double-click START_ALL_WINDOWS.bat.
5. Open http://127.0.0.1:5173
6. For API docs open http://127.0.0.1:8000/docs
